# SchemeRadar — Government Scheme Rumor Detection

A modern, production-quality **React + Vite + TypeScript + TailwindCSS + shadcn/ui** frontend for AI-powered government scheme rumor detection.

## Tech Stack

| Layer | Technology |
|---|---|
| UI Framework | React 18 + TypeScript |
| Build Tool | Vite 5 |
| Styling | TailwindCSS v3 + shadcn/ui (Radix UI) |
| Routing | React Router v6 |
| Charts | Recharts |
| Icons | lucide-react |

## Features

- **Check Rumor** — Paste any claim, get instant AI analysis with confidence score and scheme match
- **History** — Public feed + personal history with search, filter, and expand/collapse rows
- **Dashboard** — KPI cards, weekly activity line chart, rumor distribution donut chart, top schemes bar list
- **Admin Panel** — CSV dataset upload with drag-and-drop, upload progress, force rebuild
- **Auth** — Login/Signup with mock auth context, route protection
- **i18n** — English / Hindi language toggle
- **Themes** — Dark/Light mode toggle

## Design

Gov-Tech 2026 aesthetic: deep navy backgrounds, teal accent, glass/frost surfaces, subtle animations, premium typography.

## Getting Started

```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```
